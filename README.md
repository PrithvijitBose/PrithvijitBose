### 👋 About Me

I'm a software engineer who likes building things that start as a rough idea and end up as tools people actually reach for. Right now that means going deep on **agentic AI** — multi-agent orchestration, tool-calling LLMs, and the messy engineering that sits underneath "the AI just works."

- 🔭 Currently building a **Multi-Agent System** for autonomous task orchestration
- 🌱 Learning the internals of agentic workflows, planning loops, and LLM tool-use
- 🛠️ Comfortable across the stack — Python & FastAPI on the backend, React/Next.js on the front
- 💬 Always up for a conversation about AI systems, clean architecture, or good developer tooling
- ⚡ Fun fact: I'd rather refactor a working system than leave it "good enough"
